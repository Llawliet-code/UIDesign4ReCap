# 🔧 Troubleshooting Guide

**Fix common problems quickly!**

---

## 🚨 Website Won't Open

### Problem: Double-clicking does nothing

**Try these fixes:**

1. **Right-click the file** → Choose "Open with" → Select your browser
2. **Drag the file** into an open browser window
3. **Check the file name** - Should be `index.html`

**Still not working?**
- Make sure you have a browser installed (Chrome, Firefox, Edge)
- Try a different browser

---

## 🎨 Styles Look Broken

### Problem: Website looks plain or ugly

**What you'll see:**
- No colors
- Everything in a list
- No spacing
- Looks like a plain document

**Try these fixes:**

1. **Check if CSS file exists:**
   - Look for `TempUICAPSTONEREP/css/styles.css`
   - If missing, you need to add it back

2. **Refresh the page:**
   - Press `Ctrl + F5` (Windows)
   - Press `Cmd + Shift + R` (Mac)

3. **Clear browser cache:**
   - Press `Ctrl + Shift + Delete`
   - Check "Cached images and files"
   - Click "Clear data"

**Still broken?**
- Check browser console (press F12)
- Look for red error messages
- Make sure file path is correct

---

## 🌙 Dark Mode Issues

### Problem: Dark mode doesn't work

**Try these fixes:**

1. **Click the moon icon again** - Sometimes needs two clicks
2. **Clear browser storage:**
   - Press F12
   - Go to "Application" tab
   - Click "Clear storage"
   - Refresh page

3. **Try a different browser** - Some old browsers don't support it

### Problem: Dark mode won't stay on

**Fix:**
- Your browser might block localStorage
- Check browser privacy settings
- Allow cookies and site data

---

## 🔍 Search Not Working

### Problem: Nothing happens when I type

**Try these fixes:**

1. **Check JavaScript is enabled:**
   - Browser settings → Privacy & Security
   - Make sure JavaScript is allowed

2. **Refresh the page** - Press F5

3. **Check console for errors:**
   - Press F12
   - Look at Console tab
   - See if there are red errors

### Problem: Search is too slow

**This is normal!**
- Search waits 0.3 seconds after you stop typing
- This prevents too many searches
- Just wait a moment after typing

---

## 💬 Chatbot Problems

### Problem: Chatbot won't open

**Try these fixes:**

1. **Look for the orange button** - Bottom-right corner
2. **Scroll down** - Button might be hidden
3. **Refresh the page** - Press F5
4. **Check screen size** - On small screens, button might be smaller

### Problem: Chatbot opens but won't respond

**Try these fixes:**

1. **Type something and press Enter**
2. **Click the send button** (arrow icon)
3. **Try clicking a suggestion chip**
4. **Refresh and try again**

### Problem: Typing dots won't stop

**This is a bug!**
- Refresh the page (F5)
- Should fix itself

---

## ⌨️ Keyboard Navigation Issues

### Problem: Tab key doesn't work

**Try these fixes:**

1. **Click somewhere on the page first**
2. **Make sure you're not in an input field**
3. **Try Shift + Tab** to go backwards
4. **Refresh the page**

### Problem: Can't see where I am

**Fix:**
- Look for orange outline around items
- If missing, check if focus indicators are disabled
- Try a different browser

---

## 📱 Mobile Problems

### Problem: Website looks weird on phone

**Try these fixes:**

1. **Rotate your phone** - Try both portrait and landscape
2. **Zoom out** - Pinch with two fingers
3. **Refresh the page** - Pull down to refresh
4. **Clear browser cache**

### Problem: Buttons are too small

**This might be normal!**
- Some buttons are smaller on purpose
- Try zooming in
- Use landscape mode for more space

### Problem: Can't scroll

**Try these fixes:**
1. **Use one finger** to scroll
2. **Swipe up/down** not left/right
3. **Refresh the page**
4. **Close other apps** to free memory

---

## 💾 Saving Problems

### Problem: Saved projects disappear

**Why this happens:**
- Browser cleared your data
- Used private/incognito mode
- Switched browsers

**Fix:**
- Save projects again
- Don't use private mode
- Use the same browser

### Problem: Can't save projects

**Try these fixes:**
1. **Allow cookies** in browser settings
2. **Check storage space** on your device
3. **Try a different browser**

---

## 🎯 Filter Problems

### Problem: Filters don't work

**Try these fixes:**
1. **Click "Apply Filters" button**
2. **Refresh the page**
3. **Uncheck and check again**

### Problem: Can't remove filter chips

**Try these fixes:**
1. **Click the × symbol** on the chip
2. **Uncheck the filter** in sidebar
3. **Click "Clear All" button**

---

## 🖼️ Display Problems

### Problem: Text is too small

**Fix:**
- Press `Ctrl` and `+` to zoom in
- Press `Ctrl` and `-` to zoom out
- Press `Ctrl` and `0` to reset

### Problem: Text is too big

**Fix:**
- Press `Ctrl` and `-` to zoom out
- Or change browser zoom settings

### Problem: Colors look wrong

**Check:**
- Is dark mode on? (Click moon icon)
- Monitor brightness settings
- Color blindness mode in browser

---

## ⚡ Performance Problems

### Problem: Website is slow

**Try these fixes:**

1. **Close other tabs** - Free up memory
2. **Close other programs** - Free up CPU
3. **Restart browser** - Fresh start
4. **Restart computer** - If really slow

### Problem: Animations are choppy

**Try these fixes:**
1. **Close other tabs**
2. **Update your browser**
3. **Check if computer is overheating**
4. **Disable animations** in browser settings

---

## 🔄 General Fixes

### The "Turn It Off and On Again" Method

**Works for most problems:**

1. **Refresh the page** - Press F5
2. **Close and reopen browser**
3. **Restart your computer**
4. **Try tomorrow** - Sometimes servers need rest too!

### Clear Everything

**Nuclear option (fixes almost anything):**

1. Press `Ctrl + Shift + Delete`
2. Select "All time"
3. Check all boxes
4. Click "Clear data"
5. Close browser
6. Open browser again
7. Open website again

## 🆘 Still Need Help?

### Check These First:

- [ ] Is your browser up to date?
- [ ] Is JavaScript enabled?
- [ ] Are cookies allowed?
- [ ] Is internet working?
- [ ] Did you try refreshing?

### Get More Help:

1. **Press F12** to open developer tools
2. **Click "Console" tab**
3. **Take a screenshot** of any red errors
4. **Contact support** with the screenshot

### Browser Console Errors

**Common errors and what they mean:**

- **"404 Not Found"** - File is missing
- **"Failed to load"** - Check file paths
- **"Syntax error"** - Code has a typo
- **"Cannot read property"** - JavaScript error
