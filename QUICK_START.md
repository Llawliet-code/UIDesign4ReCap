# 🚀 Quick Start Guide

**Get started in 3 easy steps!**

---

## Step 1: Open the Website

1. Find the file `TempUICAPSTONEREP/index.html`
2. Double-click to open it in your browser
3. Done! The website is now running

---

## Step 2: Try These Features

### 🔍 Search for Projects
1. Look at the big search bar in the middle
2. Type what you want to find (example: "Arduino")
3. See results appear below

### 🌙 Turn On Dark Mode
1. Look at the top-right corner
2. Click the moon icon (🌙)
3. Watch the colors change!
4. Click again (☀️) to go back to light mode

### 💬 Chat with AI
1. Look at the bottom-right corner
2. Click the orange circle button
3. Type a question or click a suggestion
4. Get instant answers!

---

## Step 3: Explore More

### View a Project
- Click any project card
- Read the full details
- Click "Back to Search" to return

### Save Projects
- Click the "☆ Save" button on any project
- Go to Dashboard to see your saved items

### Use Filters
- Check boxes on the left side
- Filter by Year, Program, or Topic
- See colored chips appear at the top

---

## 🎯 Quick Tips

✅ **Use Tab key** to move between items  
✅ **Press Enter** to click things  
✅ **Use Arrow keys** to switch tabs  
✅ **Works on phones** - just open in mobile browser  
✅ **Your settings are saved** - dark mode choice stays!  

---

## ❓ Need Help?

- Click the chatbot button (orange circle)
- Ask: "How do I search for projects?"
- Or read the full README.md file
